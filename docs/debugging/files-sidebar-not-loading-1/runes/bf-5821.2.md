# bf-5821.2 — Add path validation on server startup

## Status: pending

## Description
Add path existence checks when loading workspaces and worktrees from the database during `initialize_from_db()`. Log warnings for any paths that don't exist on the current machine.

## Files
- `crates/ws-server/src/state.rs` (lines 188-204 for workspaces, lines 206-230 for worktrees)

## Changes
1. In workspace loading loop (around line 199), after inserting into the map:
   - Check `std::path::Path::new(&ws.root_path).exists()`
   - If false: `tracing::warn!(workspace_id = %id, path = %ws.root_path, "Workspace root path does not exist on this machine — path may be from a different machine")`
2. In worktree loading loop (around line 225), after inserting into the map:
   - Check `std::path::Path::new(&wt.path).exists()`
   - If false: `tracing::warn!(worktree_id = %id, branch = %wt.branch_name, path = %wt.path, "Worktree path does not exist on this machine — path may be from a different machine")`
3. Still insert the record into the map — don't skip it (other operations may not need filesystem access)

## Success criteria
- On startup with dev-machine paths on a VM, logs show warnings for each missing path
- Server still starts normally (warnings don't prevent startup)
- `cargo check -p ymir-ws-server` passes
